# OneBox

OneBox 是一款 Android 代理客户端，基于 sing-box 内核，由 OwnBox 重命名重发而来。界面为极简线条风，轻快、干净、好上手。

## 下载

- [Releases](https://github.com/smallmu1022-pixel/OneBoxForAndroid/releases)：下载最新版 APK（arm64-v8a 适用绝大多数手机），直接覆盖安装即可升级。
- 当前版本：V1.1.1

## 功能

- 订阅与节点管理：支持多种协议订阅，节点按分组展示
- 延迟测试：批量 URL 测试、TCP Ping；底栏 HTTPS 握手延迟点按直接重测
- 极简线条风：节点卡片、设置页、抽屉、溢出菜单全部扁平细线条
- 选中标识：选中节点左侧亮绿细色条
- 通知栏：连接状态与下载速度实时显示

## 使用方法

1. 添加订阅链接，更新订阅
2. 选择节点
3. 点底部纸飞机连接

## 说明

- 包名 `com.OneBox.app`，与 OwnBox 数据不互通，需全新安装
- 基于 [OwnBox](https://github.com/Own716/OwnBoxForAndroid) / SagerNet，遵循 GPLv3 开源协议
- 内核 sing-box v1.15.0-alpha.12
